# Game Collection

Piccola applicazione in HTML, CSS e JavaScript per catalogare una collezione di videogiochi in locale.

## Funzioni

- aggiunta di un gioco con titolo, piattaforma, genere, anno e studio
- rimozione di un gioco dalla lista
- salvataggio locale con `localStorage`
- filtri per piattaforma e genere
- ordinamento per titolo o anno
- ricerca per titolo o studio

## Avvio

Apri `index.html` nel browser.
